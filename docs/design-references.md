# Referencias para explorar el diseño

Selección del 12 de noviembre de 2026. Son referencias de interacción y presentación; no funcionalidades que Taski haya decidido incorporar.

| Referencia | Interacción que merece revisar | Posible aplicación a Taski |
| --- | --- | --- |
| [Superlist](https://www.superlist.com/) | Tareas, notas y discusión dentro de una lista; creación rápida y detalle posterior. | Capturar primero y ampliar contexto sin un formulario pesado. |
| [Twos](https://www.twosapp.com/) | Escribir notas, tareas y recordatorios desde una entrada sencilla. | Feedback que Juan/Alejandro puedan enviar como una frase. |
| [Things](https://culturedcode.com/things/features/) | Detalle que se despliega dentro del contexto y captura cuidada. | Interacción de la fila/tarjeta y transición a edición. |
| [Amie: tareas](https://amie.so/documentation/features/tasks) | Entrada rápida, lenguaje natural y tareas junto al calendario. | Captura en una línea; evaluar atributos sin forzar agenda. |
| [Structured](https://structured.app/) | Tareas en una línea temporal visual. | Representar progreso/contexto de forma más visual. |
| [Timestripe](https://timestripe.com/about/) | Horizontes de planificación y conexión de tareas con objetivos. | Revisar agrupación y jerarquía visual. |
| [Taskheat](https://eyen.fr/taskheat/) | Diagramas de tareas conectadas por dependencias. | Explorar tareas bloqueadas y relaciones si forman parte del alcance futuro. |

La aplicación a Taski es una interpretación de diseño, no una descripción de funcionalidades de esas apps. Las referencias principales para la siguiente exploración son Superlist, Twos y Things.

Fuentes concretas: [crear tareas en Superlist](https://help.superlist.com/en/articles/23853-create-tasks-and-subtasks), [tareas en Amie](https://amie.so/documentation/features/tasks) y [conceptos de Taskheat](https://support.eyen.fr/hc/en-us/articles/360016550820-What-is-Taskheat).
