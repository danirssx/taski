# Dominio

Reglas y tipos del producto, independientes de UI, transporte y persistencia. Los tickets se implementarán en B3; esta carpeta no contiene entidades ficticias ni el almacenamiento del spike Python.

Puede importar solo otros módulos de dominio. No importa React, Cloudflare, HTTP, SQL ni APIs del navegador. El check de fronteras y el typecheck del núcleo sin tipos de plataforma protegen esta separación.
